# Reproduction scope

The next iteration will reproduce the project described in the user-provided
reference document. The current account-protection harness is the starting point;
it does not yet constitute a reproduction of that project.

Before implementation:

1. Read the reference and map its inputs, outputs, architecture, and evaluation.
2. Choose a project name that matches the reference scope.
3. Record acceptance criteria and identify reusable harness components.
4. Implement and verify an end-to-end baseline before extending it.

Reference access is currently unresolved; project-specific requirements and the
new name remain pending until the document can be read.
